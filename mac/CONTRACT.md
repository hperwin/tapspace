# TapSpace mac: shared contract

Target: `TapSpace` (Sources/TapSpace), Swift 6 tools, language mode v5, macOS 26. Builds clean (`swift build`, 0 errors, 0 warnings) as of the stabilize commit.
Everything below is depended on across lanes. Changing a signature listed here breaks other lanes: ADD new members instead of changing or removing existing ones. If you truly need a breaking change, put it in your final report so the orchestrator can schedule it.

## Models (API.swift, core). All `Decodable, Equatable`

- `Ticket` (Identifiable): `id, agent, title, campaign?, version, versions: [TicketVersion], status`; `entry(_ v:)`, `current`, `isVideo`, `videoDeleted`, `lastTs`, `mediaPath(_ v:) -> String` (`/shots/<id>/<v>.<ext>`), `versionKey` (`"id#v"`).
- `TicketVersion`: `v, note?, ts, media?, ext?, video_deleted?`; `isVideo`.
- `Agent` (Identifiable, id = name): `name, state ("thinking"|"here"|"away"), seen, first?, where?, last, count, last_master?`; `key` = `"agent:" + name`.
- `ChatMessage` (Identifiable): `id: Int, agent, role ("master" = agent side, else Hayden), body, ts, images: [String]` (`/chat-media/<file>` paths, [] when none; the bubble grid and the pill read it directly).
- `Tap` (Identifiable, id = key): `key ("owner/repo#n"), repo, number, title, url, status ("flying"|"needs-you"|"boarding"|"landed"), goals: [TapGoal], messages: [TapMessage], created, closed?, last`; `name`, `repoName`.
- `TapGoal { text, done }`, `TapMessage { who ("you" = Hayden), body, ts (ISO), seen?, url? }` + `date: Double`.
- `TapsResponse { me, items: [Tap], fetched, error }`, `ActivityRow { campaign, agent, verb, detail, kind, age, state }` + `key`, `Sessions { working, recent }`, `ActivityResponse { rows, sessions }`.
- Free functions: `parseISO(_:) -> Double` (memoized), `when(_ ts:) -> String`, `timeago(_ ts:) -> String`.
- Masters (served on `GET /api/agents`): `Agent` adds `progress: AgentProgress?`, `notes: [AgentNote]` (server-filtered by its read mark), `notesRead: Double?` (vars with defaults, so the memberwise init stays). `AgentProgress { goal, steps, current (0-based; == steps.count is done), note?, updated }` + `isDone`, `currentText`. `AgentNote` (Identifiable, id `"ticket#version"`) `{ ticket, version, title, note, ts, thumb }` (`thumb` is "" for a video: show the title). `AgentLink` (Identifiable, id `"a|b"`) `{ a, b, last, count, summary, active, from }` + `to`, `touches(_:)`, `other(_:)`. `AgentsBoard { agents, links }`. `Ticket.owner: String?` (the owning master's NAME; never shown).
- Update cards (served on `GET /api/chat`): `ChatMessage` adds `card: ChatCard?` (nil on plain rows and on a card `v` this build cannot draw: the row shows its `body`), `answer: ChatAnswer?` (Hayden's row) and `nonce`. `ChatCard { v, line, face, faces: [key: CardFaceInfo], visual: CardVisual?, items: [CardItem], images: [CardImage], ask: CardAsk?, action: CardAction? }`. `CardFaceInfo { kind (lead|master|tap|project), look?, title, initial, state?, phase? }`. `CardVisual { kind (progress|timeline|graph|word), done, total, from?, label, steps, at, points, text }`. `CardItem { ref, kind, title, name?, note, phase?, word, goals, state?, progress: CardItemProgress?, was: CardWas? }`: `name` is the sender's short name (nil when none or blank), shown in place of the title in its row and in a single-subject header. `CardImage { label, from: CardImageSource? }` (`{tap, i}`: a tap's proof). `CardAsk { q, checks: [CardCheck { id, label }], text }`. `CardAction { kind ("tap_accept"), tap }`: the card's one action, Accept and Not quite for that landed tap. `ChatAnswer { card, image?, verdict (approve|change), note, checks, text, action (accept|deny) }`.
- The lead and the fleet: `Agent` adds `role` ("lead" on the lead's row; `isLead`), `parent`, `look` (0 the lead's, 1...17 the others; nil: the plain orb) and `activity: AgentActivity?` (the lead's row only: `{ state (working|waiting|idle|switching|gone), word, detail, since }`). `AgentsBoard` adds `fleet: [FleetEntry]` (everything under the lead, in the server's order; [] with no lead) and `focus: String?` (the thread key of Hayden's newest own message). `FleetEntry { key, kind (master|tap), title, look?, initial, state, phase, word, done, total, needsYou, working }`.
- Decoding is tolerant: every list is `Lossy<T>` (a malformed row is skipped, never fails the poll); missing non-identity fields take defaults. Memberwise inits are kept.

## API (API.swift, core): `enum API`

- `API.base: URL` (TAPSPACE_URL, default http://127.0.0.1:4747), `API.allowWrites: Bool` (false under --demo/--snapshot), `API.isLocal`.
- `get<T>(_:_:_:)`, `data(_ path:) -> Data`, `post(_ path:, _ body:, speaksForHayden: Bool = true) -> [String: Any]` (content-type json, no Origin header; speaksForHayden posts are refused when `allowWrites` is false).
- `state() -> [Ticket]`, `agents() -> [Agent]`, `chat(_ agent:) -> [ChatMessage]`, `taps() -> TapsResponse`, `activity() -> ActivityResponse`. All `async throws`.
- Added: `postData(_:_:speaksForHayden:) -> Data`, `say(_ body:, toAgent:) -> ChatMessage?` (POST /api/chat, returns the stored row), `APIError.decode` (server up, bad payload; never flips the connection to down), `APIError.isOffline(_:)`.
- Masters: `board() -> AgentsBoard` (GET /api/agents, agents plus the top-level `links`; `agents()` is `board().agents`), `markAgentRead(_ name:)` (POST /api/agents/read `{name}`, speaksForHayden).
- Cards: `answer(_ a: ChatAnswer, toAgent:, nonce:) -> ChatMessage?` (POST /api/chat with `answer`; the server writes the body; the nonce lands a retry on the same row) and `acceptTap(_ key:, card: Int? = nil) -> ChatMessage?` (POST /api/taps/accept `{key, card?}`; with `card` the server checks that card's Accept is this tap's, then returns the card's "Accepted" answer row). Both speak for Hayden.

## Store (Store.swift, core): `@MainActor @Observable final class Store`, `Store.shared`

- Enums: `Tab { visual, chat }` (String raw), `Connection { connecting, live, down }`. Structs: `PendingMessage { id, key, body, ts, demo }`, `Toast { id, text }`.
- State (read-only outside core unless noted): `connection, tickets, ticketsLoaded, agents (rw), agentsLoaded, chats: [agentName: [ChatMessage]], taps: TapsResponse, activity, sessions, pending, confirmed, decided, reads, windowKey (rw), toast (rw), focusCard (rw), tab (rw), thread (rw, a thread key: "agent:NAME" or "owner/repo#n")`.
- `tabProgress: SpringBox` (0 visual .. 1 chat). Hooks: `onTickets: ([Ticket]) -> Void`, `onChange: () -> Void`.
- `start()` begins polling and, if the server is down, starts the one `CoreServer.plan()` allows (retries every 20 s while down). Cadence: state 1.5 s always; agents 2 s and taps 5 s while live (the pill needs them); activity 2 s only while the main window is visible; the open agent chat 1.5 s only while visible AND on the Chat tab (a thread picked elsewhere is fetched once, so the tab opens on loaded content). Unchanged polls write nothing. `onTickets`/`onChange` fire only on change.
- Added: `windowVisible` (main window on screen; forced true under --snapshot/--demo), `refreshAll() async` (every endpoint once, awaited: harness), `pollers` / `statePoller` ... `activityPoller` (`CorePoller`: `kick()`, `now() async`, `count`), `surfaces` (`CoreSurfaces`).
- Reads persist in UserDefaults key `reads` (coalesced writes, pruned). First launch ever (no saved reads) marks existing threads read once data loads. Unread agent threads that are not open get their chat fetched once so the pill can quote the reply.
- Threads: `threadMissing`, `threadKeys`, `agent(_ key:)`, `tap(_ key:)`, `readAt(_:)`, `markRead(_:)`, `lastTheirs(_:)`, `isViewing(_:)`, `isUnread(_:)`.
- Counts: `waitingCards: [Ticket]`, `needsYouTaps: [Tap]`, `unreadAgents: [Agent]`, `visualBadge`, `chatBadge`, `waitingTotal`.
- Actions: `decide(_ t:, approve:, message:) async -> Bool` (optimistic: leaves the counts at once, rolls back on failure), `send(_ body:, to key:) async -> Bool` (trims; agent -> /api/chat and the returned row replaces the bubble immediately via `confirmed`; tap -> /api/taps/say, bubble kept until GitHub shows a matching comment written after it, max 2 min), `demoBubble(_:to:)`, `show(_ text:)` (toast).
- `Images.shared` keeps the 160 most recent decoded bitmaps (`limit`).
- Extensions living in other lanes' files (owned by that lane, callable by all): `isViewingCandidate`, `open(_ key:)` (sets the thread, marks it read and reads its notes) (ChatView.swift, chat); `pillItems: [PillItem]` (PillView.swift, pill).
- `Images.shared` (Store.swift): `cached(_ path:, maxPixel:) -> NSImage?`, `load(_ path:, maxPixel:) async -> NSImage?` (downsampled, deduped).
- Cards, the lead and the focus: `fleet: [FleetEntry]`, `focus: String?`, `isQuiet(_ key:)` (the focus or the thread on screen: news there never badges), `newsTaps` (holding, or an unread reply, never quiet; `chatBadge` = `newsTaps` + `unreadAgents`, and the pill lists the same taps), `insertRow(_ row:)` (a row the server just stored for Hayden, in its thread before the next poll), `answer(_ a:, to agent:) async -> Bool` and `accept(tap:card:) async -> Bool` (CoreCard.swift: through `CardAnswers.shared`, shown at once, rolled back on a refusal).
- Masters: `links: [AgentLink]` ([] on older servers), `notesCut` (the local read cut per NAME), `progress(for key:)`, `notes(for key:)` and `notes(for agent:)` (visible notes, newest first; [] for taps), `hasNotes(_:)`, `talking(_:)` (active links to another master on the rail), `agentTitle(_ name:)`, `readNotes(_ key:)` (reads that master's card notes: optimistic, then POST /api/agents/read, refused under --snapshot/--demo and never rolled back). Notes are read only by `open(_:)` (an explicit open: rail row, note row, progress card) and when one lands while that thread is on screen with the window key, never by a tab switch or window focus alone; `markRead(_:)` is unchanged (replies only). Notes never count in `chatBadge`, `unreadAgents` or the pill.

## CoreServer (CoreServer.swift, core)

- `enum CoreServer`: `plan()` (nil, or what to start: the live rig via `tap.py up` for the default 127.0.0.1/localhost:4747 with no `TAPSPACE_DATA`; an app-owned `server.py` on `TAPSPACE_DATA` and the URL's port, stopped by a supervisor when the app exits; nothing for any other port), `canStart: Bool` (static, MainActor-free; the shell's ConnectingView says "STARTING TAPSPACE" only when true), `start()`. `Store.bootServerIfNeeded()` goes through it.

## Motion (Motion.swift, core)

- `struct Spring(value, stiffness:, damping:)` / `Spring(value, SpringPreset)`: `step`, `advance(dt) -> Bool` (substepped at 480 Hz, snaps when settled), `snap(to:)`, `use(_:)`, `settled`, `atRest`.
- `SpringPreset { stiffness, damping }` presets: `.smooth` 260/30, `.liquid` 260/24, `.snappy` 420/36, `.pop` 380/15, `.gentle` 120/21, `.draw` 70/16, `.droplet` 420/19, `.spreadW` 300/25, `.spreadH` 190/23, `.retractW` 330/34, `.retractH` 420/38, `.bulge` 340/21 (SnappWAU's droplet radius), `.tab` 220/26. `dampingRatio`; `animation` / `Animation.spring(.liquid)` = the same physics for SwiftUI-driven bits (numericText, opacity), so everything moves alike.
- `@MainActor protocol MotionDriver: AnyObject { func advance(_ dt: Double) -> Bool; func finish() }`.
- `@MainActor final class Motion`: `Motion.main` (window), `Motion.pill` (pill panel). `attach(to: NSView)` (CADisplayLink 80-120 fps, paused when still), `activate(_ driver)`, `deactivate(_ driver)`, `wake()`, `keepAwake: (() -> Bool)?`, `frames`, `longestFrame` (worst gap since reset, seconds), `isPaused`, `isStill`, `activeCount`, `settleAll()` (snapshots), `run(seconds:step:)` (offline stepping for snapshots). Steps to `targetTimestamp`; any driver (re)activated during a frame (e.g. from a completion) is kept, not only SpringBoxes.
- `@MainActor @Observable final class SpringBox: MotionDriver`: `init(_ v, _ preset = .smooth, motion: Motion? = nil)` (nil = `.main`; call sites passing `.pill` are unchanged), `set` to the target it already rests on is a no-op (no frame), `value` (observed), `target`, `velocity`, `atRest`, `set(_ t, _ preset?, delay:, then:)`, `snap(_:)`, `kick(_ velocity)`, `onStep`. Create SpringBoxes from MainActor code only (not as a default stored-property value of a nonisolated struct).
- **Never `scaleEffect` an AppKit-hosted view (RingView, OrbView, BreathingDot, TypingDots, SessionDots, LayerHost, GrowingTextView) to exactly 0**: AppKit asserts on the singular transform (`NSViewGetTransformToDescendant`) and the app aborts. Clamp to `max(0.001, v)` or fade with opacity instead.
- Helpers: `lerp` (CGFloat/Double), `clamp01`, `smoothstep(e0, e1, x)`, `lerpRect`, `pixel(_:)` (round to half point), `aspectFit(_:in:)`, `metaballNeck(c1, r1, c2, r2, ...)`.

## Harness entry point (Harness.swift, harness)

```swift
@MainActor enum Harness {
    static func run(flags: Flags, app: AppDelegate)   // called once at the end of applicationDidFinishLaunching
    static func wait(_ timeout: Double, every ms: Int = 50, _ cond: () -> Bool) async -> Bool
    static func log(_ s: String)                       // print + flush (stdout lines start SNAPSHOT / DEMO)
}
```
- `--snapshot <dir>` -> `HarnessSnapshot` (HarnessSnapshot.swift): waits for cards, media and change boxes, then poses and renders `01-visual, 02-visual-notes, 03-lightbox, 04-chat-agent, 10-chat-wide, 05-chat-agent-thinking, 11-chat-card, 12-chat-rail-open, 06-chat-tap, 07-pill-collapsed, 08-pill-bulging, 09-pill-expanded` (in that order) at exactly 2x with `cacheDisplay`, writes `scenes.json` (size, ink, note per scene, problems, and `masters`), exits 0 (all good) or 1; refused, 2. 04 opens (`Store.open`) a master without card notes, after setting the thread before the tab and `windowKey = true`; 10 is that pose in a 1512 x 887 window; 05 opens a thinking master with notes and records `notes_after_open` (a problem when any are still listed); with no thinking master on the server it logs `SNAPSHOT skipped 05-chat-agent-thinking` instead of a problem. 11 is the lead's thread with its update cards at rest and their answers folded in (a problem when it has none); 12 is the rail with the lead's fold open. `masters` is what the app decoded before any thread opened: `agents, with_progress, notes, links, links_active, owned_cards`. Scene notes show titles, never NAMEs, keys or numbers. `HarnessSnapshot.render(_ view:, scale:) -> CGImage?` and `ink(_:)` are reusable.
- `--snapshot <dir>` with `TAPSPACE_LINK_FRAMES=1` -> `HarnessLink.run(app:dir:)` (HarnessLink.swift) instead of the scenes: `LINKCHECK` (the board's rules), then 2x frames `f000.png...` at 30 per second of motion plus `frames.json` (the connector forming, chasing, turning, ending); `HarnessLink.asked`, `checks()`, and the `links` / `phase` pose state the panel reads.
- `--snapshot <dir>` with `TAPSPACE_CARD_FRAMES=1|live|checks` -> `HarnessCard.run(app:dir:)` (HarnessCard.swift): `CARDCHECK` and `CARDMOTION` (the card rules on synthetic rows), then 2x frames at 30 per second plus `frames.json`. `1` replays the lead's newest picture card and question card arriving and being answered (nothing is posted); `live` waits for new cards on a scratch server, records their real arrival and answers them for real through `CardAnswers`; `checks` stops after the checks. `live` is the one harness mode that writes, and only to the scratch server `TAPSPACE_URL` names (`ChatHarness.refusal()`).
- `--demo` -> `HarnessDemo.shared.start(app:fps:)` (HarnessDemo.swift): a 10 s loop forever, logging `DEMO loop=N t=T step`.
- `--fps` logging itself lives in App.swift (`startFPSLog`, shell): per second `main=<frames> moving|still [paused] drivers=N run=<s the link ran> rate=<frames/run> worst=<longest gap>ms` (`Motion.runTime`, `longestFrame`, reset each second). `Scripts/fps.sh` summarizes it; judge smoothness by `rate` (a second where motion ends early has few frames but a full rate).
- What the harness calls in other lanes (keep these): `Store.tab/thread/threadKeys/agents/chats/taps/tickets/windowKey/links/notes(for:)/open(_:)/demoBubble/ticketsLoaded/agentsLoaded/visualBadge`, `Agent.title/notes/progress`, `AgentLink.active`, `Ticket.owner`, `Tap.title`, `ChatHarness.refusal()`, `VisualModel.cards/mediaReady/toggleNotes/openLightbox/closeLightbox/lightbox`, `CardModel.ticket/image/highlights/notesOpen/notesText`, `Lightbox.image`, `PillController.panel/liquid/simMouse/wake(onlyIfNear:)/pose(_:)/releasePose()` + `PillController.Pose` (PillHarness.swift, pill), `PillLiquid.anchorLeft/top/shapeRect/debugState/pillH`, `Motion.main/pill.settleAll()`, `AppDelegate.window/store/visual/pill`.
- Scripts (mac/Scripts): `install.sh` (release, bundle, icon, ad-hoc sign, /Applications beside a running copy without quitting, relaunching or activating it; `BUNDLE_ONLY=1` stops at the signed `.build/TapSpace.app`; `OPEN=1` opens it with `open -g` and `TAPSPACE_BACKGROUND=1` only when no copy runs), `seed.sh <port> [dir]` (real screenshots, two masters with goal cards and owned cards, two notes, chat; each master as its own scratch session) / `seed.sh --link <dir>` (one exchange between them, active for 10 minutes) / `seed.sh --copy <port> [dir]` (a copy of the live cards, chat and agents; no token, pairing or devices) / `seed.sh --stop <dir>` (every mode wipes or stops only a folder it marked), `fps.sh <url> [secs] [bin]` (on screen; refuses 4747), `verify.sh [port] [out] [secs]` (build, seed, link, the served counts, offscreen scenes and link frames under a front-app and Dock watch, the app's `masters` against the server's, link.mp4; `LINK=0` skips the frames, `CARD=0` skips the card frames and card.mp4, `FPS=1` adds fps.sh). Resources: `Info.plist` (com.hayden.tapspace), `TapSpace.icon` (compiled by actool at install).
- Verification never takes the screen: `--snapshot` (scenes and link frames) runs offscreen as an accessory app and never activates; `--demo`, fps.sh and the ChatHarness drives run on screen, only with the go of whoever is using the Mac. Nothing verifies against the live port 4747.
